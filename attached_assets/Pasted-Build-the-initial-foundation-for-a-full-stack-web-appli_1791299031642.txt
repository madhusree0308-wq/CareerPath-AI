Build the initial foundation for a full-stack web application called CareerPath AI.

Project tagline:
"Your skills. Your goal. Your roadmap."

Purpose:
CareerPath AI is an AI-powered Student Career and Skill Planner. It helps students identify skill gaps between their current skills and a target career, then generates a personalized learning roadmap.

Tech stack:
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: Supabase PostgreSQL
- Authentication: JWT + bcrypt
- Validation: Zod
- AI: Google Gemini API through the backend only
- HTTP client: Axios
- Styling: Tailwind CSS
- Icons: Lucide React

Architecture:
Use a clean full-stack structure with separate client and server directories.

Create:

/client
  /src
    /components
    /pages
    /layouts
    /services
    /hooks
    /utils

/server
  /src
    /controllers
    /routes
    /middleware
    /services
    /models
    /utils
    /config

   - CareerPath AI

6. Create placeholder pages:
